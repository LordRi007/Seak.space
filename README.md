# Sath Chhunseak | Software Engineer & Full Stack Portfolio

Redesigned modern interactive developer portfolio built with **React 19**, **Vite**, **Tailwind CSS v4**, and custom animations.

Live Domain: [seak.space](https://www.seak.space/)  
GitHub: [LordRi007/Seak.space](https://github.com/LordRi007/Seak.space)

---

## ⚡ Key Highlights & Features

- **Interactive Canvas Ambient Universe**: 60fps dynamic constellation node background responding to mouse coordinates.
- **Interactive NBC Bakong KHQR & POS Simulator**: Live interactive checkout simulation showcasing Sath's signature POS development experience (EMVCo dynamic QR generation, CRC-16 encoding, simulated asynchronous MD5 polling, instant confetti feedback).
- **Interactive Developer Shell**: Terminal prompt in the hero section where visitors can type commands (`help`, `skills`, `projects`, `khqr`, `whoami`, `contact`, `clear`).
- **Interactive Project Showcase**: Filterable cards with 3D tilt effects, live demo badges for [AuraPOS](https://aurapos.store) and [SmartPOS Cafe](https://www.poscafe.online/), and modal architectural breakdowns.
- **Technical Skills Matrix**: Categorized proficiencies (React, Laravel, MySQL, Bakong KHQR, Spring Boot, etc.) with animated proficiency indicators.
- **Milestones & Journey**: Blending 7-Eleven retail POS operations with Year 4 Bachelor of Software Engineering (BSE) academic coursework at BELTEI International University.
- **Quick-Contact Matrix**: Direct one-click copy feedback for email & phone, plus validated messaging form with visual confetti celebration.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Glassmorphism utilities
- **Icons**: Lucide Icons + Custom SVG Brand components
- **Effects**: HTML5 Canvas Particle Engine + Canvas Confetti
- **Deployment**: Automatic GitHub Actions deployment to GitHub Pages, or Vercel / Netlify ready.

## 🚀 Local Development

To run the development server locally:

```bash
npm install
npm run dev
```

To build for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
