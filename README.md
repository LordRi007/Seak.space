# Sath Chhunseak | Software Engineer & Full Stack Portfolio

Clean, modern, and high-performance developer portfolio built with **React 19**, **Vite**, and **Tailwind CSS v4**.

Live Domain: [seak.space](https://www.seak.space/)  
GitHub: [LordRi007/Seak.space](https://github.com/LordRi007/Seak.space)

---

## ⚡ Highlights

- **Ambient Particle Universe**: Smooth 60fps HTML5 Canvas particle background subtly responding to mouse movement.
- **Dynamic Hero Section**: Real-time role typewriter, status beacon, developer signature card with one-click copy, and stats.
- **Featured Systems**:
  - **AuraPOS**: High-performance Point of Sale with dynamic NBC Bakong KHQR payments and MD5 polling verification ([aurapos.store](https://aurapos.store)).
  - **SmartPOS Cafe**: Cafe POS and inventory management suite with sales calendar tracking and RBAC ([poscafe.online](https://www.poscafe.online/)).
- **Skills Matrix**: Organized frontend, backend, database, and fintech tool proficiencies.
- **Journey**: Highlighting Year 4 BSE coursework at BELTEI International University alongside real-world 7-Eleven retail POS operations.
- **Direct Connect**: One-click copy email & phone, social channels, and responsive contact form.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Glassmorphism
- **Icons**: Lucide Icons + Custom SVG Brand icons
- **Effects**: HTML5 Canvas Particle Engine + Canvas Confetti

---

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
